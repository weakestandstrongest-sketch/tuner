# Tuner & Metronome

ブラウザで動くチューナー＋メトロノーム（`index.html` 1ファイル、外部依存なし）。

- **チューナー**: マイク入力で音程検出（YIN）、スマイル表示、セント／Hz表示、ロングトーン判定スコア、ピッチ履歴グラフ
- **サウンド**: 基準音（ドローン）、音色5種、完全5度の重ね
- **メトロノーム**: 30–300 BPM（小数2桁まで）、回転ダイヤル、TAP、拍子13種、細分化リズム、拍ごとのアクセント、音色5種、テンポアップ練習
- **設定**: A4 = 415–466 Hz、平均律／純正律／ピタゴラス音律、主音、移調（C・B♭・E♭・F・A・G 管）、音名表記

マイクの利用には HTTPS が必要です（GitHub Pages などで公開してください）。
