# Tuner & Metronome

ブラウザで動くチューナー＋メトロノーム（`index.html` 1ファイル、外部依存なし）。

- **チューナー**: マイク入力で音程検出（YIN）、スマイル表示、セント／Hz表示、ロングトーン判定スコア、ピッチ履歴グラフ
- **サウンド**: 基準音（ドローン）、音色5種、完全5度の重ね
- **メトロノーム**: 30–300 BPM（小数2桁まで）、回転ダイヤル、TAP、拍子13種、細分化リズム、拍ごとのアクセント、音色5種（音の高さ調整つき）、テンポアップ練習
- **設定**: A4 = 415–466 Hz、平均律／純正律／ピタゴラス音律、主音、移調（C・B♭・E♭・F・A・G 管）、音名表記

マイクの利用には HTTPS が必要です（GitHub Pages などで公開してください）。

## 統合したアプリ
- **コード**（`chords/`）：五度圏のコードホイール。元は `music-code` リポジトリ。
- **純正律**（`just/`）：構成音からコード名を判定し、純正律のずれを表示。元は `code2` リポジトリ。

どちらもタブの中に表示し、`embed.css` で配色と下のタブバー用の余白を合わせています。

## 更新の反映
変更をコミットする前に `sh tools/bump-version.sh` を実行してください。`version.json` とファイル参照の `?v=` が新しい番号になり、
開いているアプリは次に表示されたときに新しい版へ自動で切り替わります。
